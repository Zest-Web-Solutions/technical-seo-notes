# Technical SEO Checklist

A strong technical SEO foundation improves crawlability, indexing efficiency, and performance.

## Crawlability

* clean robots.txt
* valid sitemap.xml
* proper internal linking
* working canonical tags
* crawlable HTML structure

## Performance

* optimized Core Web Vitals
* compressed images
* lightweight JavaScript
* reduced render blocking

## Semantic SEO

* structured heading hierarchy
* semantic HTML
* schema markup
* topical internal linking

## Indexing

* no broken pages
* canonical consistency
* indexable important pages
* URL normalization

Technical SEO works best when paired with clean development architecture.
